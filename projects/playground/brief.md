# Brief: Детская площадка

## Участок
- 8x8 метров, между жилыми блоками
- Плоский рельеф
- Север сверху, проезжая часть с юга
- София, Болгария (континентальный климат)

## Концепция
- Три эллиптических острова, соединённые мостиками
- Остров 1: песочница
- Остров 2: горки
- Остров 3: лазалки/climbing
- Возрастной микс: 0-12 лет

## Покрытия
- Острова: резиновое покрытие (EPDM)
- Между островами: насыпной гравий
- Мостики: резиновые плашки

## Обязательные элементы
- Ограда с шумоизоляцией от проезжей части (юг)
- Наземные светильники
- Лавочки для родителей по периметру
- Урны

## Ограничения
- Нет ограничений по высоте
- Без бюджета — рисуем красиво
- Реальный проект
