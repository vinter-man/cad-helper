# Project: Детская площадка между блоками

## Design Concept

Три органических острова-эллипса на гравийном "море", соединённых резиновыми мостиками. Каждый остров — своя возрастная тема: малыши (песочница), средние (горки), старшие (лазалки). Лавочки для родителей по периметру. Шумозащитный забор от проезжей части с юга. София, Болгария.

## Site Summary

- Площадка: 8x8 метров
- Климат: София, континентальный (жаркое лето, холодная зима, до -15)
- Стиль: современный, органические формы
- Ключевое ограничение: проезжая часть с юга — нужна ограда + шумоизоляция
- Ключевое желание: три тематических острова, соединённые мостиками

## Build Phases

1. Границы и покрытие (площадка, гравий, ограда, шумозащита)
2. Острова (три эллипса с резиновым покрытием)
3. Оборудование (песочница, горки, climbing dome)
4. Мостики (три резиновых мостика)
5. Мебель (лавочки, урны)
6. Освещение (наземные светильники)
