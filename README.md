# CAD Helper

Инструмент за генериране на DXF чертежи за AutoCAD. Описваш какво искаш с думи, получаваш готов `.dxf` файл.

## Как работи?

1. Отваряш тази папка във VS Code с Claude Code
2. Описваш какво искаш (на български, руски или английски)
3. Claude те интервюира, прави план, рисува, проверява
4. Получаваш готов `.dxf` файл — отваряш го в AutoCAD

Няма нужда да пишеш код. Просто описваш и получаваш.

## Първоначална настройка (само веднъж)

```bash
pip install -r requirements.txt
```

## Как протича работата по нов проект

Claude следва 4 фази:

### Фаза 1: Интервю

Claude те пита за всичко важно преди да рисува каквото и да е:

- Колко голям е парцелът? Каква е формата?
- Какъв е климатът? Колко слънце получава дворът?
- Какъв стил искаш? (японски, средиземноморски, модерен, див?)
- Какво задължително трябва да има? (тераса, барбекю, езерце?)
- Кой ще ползва градината? Деца? Домашни любимци?
- Колко време имаш за поддръжка?

Колкото по-подробно отговориш, толкова по-добър ще е резултатът.

### Фаза 2: План

Claude създава подробен план в текстов файл:

- Концепция на дизайна (каква идея стои зад всичко)
- Зони — какви, къде, колко големи
- Списък на всеки елемент — позиция, размер
- Растителна палитра — какви растения и защо
- Материали — камък, дърво, чакъл

**Ти преглеждаш плана и казваш "ок" или "промени X".** Нищо не се рисува преди да одобриш.

### Фаза 3: Изпълнение

Claude генерира DXF файла. Той самият пуска скрипта и проверява дали всичко се генерира без грешки.

### Фаза 4: Проверка

Преди да ти предаде файла, Claude минава през контролен списък:

- Всички елементи вътре ли са в парцела?
- Пътеките водят ли до правилните места?
- Има ли достатъчно разстояние между дърветата и къщата?
- Всеки елемент на правилния layer ли е?

Ако нещо не е наред — поправя го и проверява отново.

## Бързи промени

За дребни промени не минаваш през 4-те фази. Просто казваш:

> "Премести пейката 2 метра наляво"

> "Добави още едно дърво до езерцето"

> "Смени цвета на зоната за барбекю"

Claude директно променя, пуска скрипта, готово.

## Какво може да рисува

| Категория | Елементи |
|-----------|----------|
| Основа | Парцел, къща, ограда с портички, компас, размери |
| Зони | Тераса, барбекю зона, градина, морава |
| Пътеки | Криволинейни пътеки, каменни стъпала (тоби-иши) |
| Конструкции | Пергола, пейки, маса със столове, барбекю |
| Японска градина | Дзен градина, тории, цукубай, бамбукова ограда, нивaki |
| Вода | Езерце, поток, мост |
| Растения | Дървета, храсти, клумби, морава, жив плет, мъх |
| Осветление | Каменни фенери, прожектори, фенери по пътека |
| Настилки | Плочки (микс, решетка, елочка, бордюр) |

## Примерен проект: Японска градина

В папка `projects/backyard/` има готов проект — японска градина за парцел 25x40 метра:

- Дзен градина с камъни и нагребан чакъл
- Езерце за кои с поток и дървен мост
- Чайна градина с цукубай
- Нивaki борове, кленове, сакури, бамбук, азалии, мъх
- Каменни фенери вместо модерни лампи
- Каменни стъпала вместо обикновени пътеки

604 елемента в 36 AutoCAD слоя.

```bash
python projects/backyard/build.py
```

## Единици

Всичко е в **милиметри**. Ако кажеш "3 метра", Claude автоматично конвертира в 3000 мм.

## Структура на папките

```
cad-helper/
├── plans/          ← планове и интервюта
├── reviews/        ← проверки преди предаване
├── lib/            ← библиотека за рисуване (не пипай)
├── projects/       ← твоите проекти
│   └── backyard/   ← примерен проект
└── generate.py     ← бързо генериране на настилки
```

## Изисквания

- Python 3.10+
- AutoCAD 2010+ (за отваряне на DXF файловете)
